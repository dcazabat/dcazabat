## Cómo trabajo

**Spec → Clarificar → Plan → Tareas → Implementar → Validar.**

Trabajo con clientes de IA como **OpenCode** y **Hermes**, y con agentes especializados, dentro de Spec-Driven Development: primero la especificación, después la implementación y al final la validación contra criterios medibles. Ninguna entrega se cierra sin build limpio y verificación requisito por requisito.
